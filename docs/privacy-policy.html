Privacy Policy

Context Explain Chrome Extension — Last updated: May 2026

Overview

Context Explain is a browser extension that provides AI-powered explanations, translations, and image analysis for content you select while browsing. This policy explains what data the extension handles and how.

Data We Do NOT Collect

  • We do not collect, store, or transmit any data to our own servers.
  • We do not have any servers. The extension has no backend infrastructure.
  • We do not use analytics, tracking pixels, or any telemetry.
  • We do not require an account or any form of registration.
  • We do not sell or share any data with third parties.

Data You Provide

To use the extension you must supply an API key from an AI provider of your choice (e.g. OpenAI, Anthropic, DeepSeek, or a compatible service). This key is stored locally in your browser using Chrome's chrome.storage.sync API, which may sync across your Chrome profile's devices via your Google account. The key is never sent anywhere except directly to the API endpoint you configure.

Data Sent to AI Providers

When you use the extension, the following data is sent directly from your browser to the AI provider you have configured:

  • The text you selected on a webpage
  • A short surrounding context snippet (a few sentences before and after the selection)
  • For image analysis: image data from the image you right-clicked
  • Your follow-up questions
  • Your API key (as a Bearer token in the Authorization header)

This data is sent directly from your browser to the provider's API endpoint. It does not pass through any intermediate server operated by Context Explain. Each provider's own privacy policy governs how they handle the data you send them.

Local Storage

Your conversation history is stored locally in your browser via chrome.storage.local. This data never leaves your device unless you explicitly use the "Export JSON" feature to save it yourself. You can delete all history at any time from the History tab in the extension.

Permissions

The extension requests the following permissions:

  • storage / unlimitedStorage — to save your settings and conversation history locally
  • contextMenus — to add right-click options for image analysis
  • host_permissions (<all_urls>) — required to inject the explanation panel on any webpage you visit, and to make API requests to the provider endpoint you configure

Children's Privacy

This extension is not directed at children under 13. We do not knowingly collect any information from children.

Changes to This Policy

If this policy changes materially, we will update the date above and note the change in the extension's release notes on the GitHub Releases page.

Contact

Questions or concerns? Open an issue on GitHub.

隐私政策（中文）

Context Explain Chrome 扩展 — 最后更新：2026 年 5 月

概述

Context Explain 是一款浏览器扩展，用于为你在浏览时选中的内容提供 AI 解释、翻译和图片分析。 本政策说明该扩展如何处理数据。

我们不收集的数据

  • 我们不向任何服务器收集、存储或传输任何数据。
  • 本扩展没有任何后端基础设施。
  • 我们不使用任何分析工具、追踪像素或遥测。
  • 不需要账户或任何形式的注册。
  • 我们不向任何第三方出售或共享数据。

你提供的数据

使用本扩展需要提供你选择的 AI 服务商的 API Key（如 OpenAI、Anthropic、DeepSeek 或兼容服务）。 该密钥通过 Chrome 的 chrome.storage.sync API 存储在本地浏览器中， 可能通过你的 Google 账户在多设备间同步。该密钥只会发送到你配置的 API 端点，不会发送到其他地方。

发送给 AI 服务商的数据

使用扩展时，以下数据会从你的浏览器直接发送到你配置的 AI 服务商：

  • 你在网页上选中的文字
  • 选中内容前后的简短上下文片段
  • 图片分析时：你右键点击的图片数据
  • 你的追问问题
  • 你的 API Key（作为 Authorization 请求头中的 Bearer token）

这些数据直接从你的浏览器发送到服务商的 API 端点，不经过 Context Explain 的任何中间服务器。 各服务商自身的隐私政策管理他们如何处理你发送的数据。

本地存储

你的对话历史通过 chrome.storage.local 存储在本地浏览器中，除非你主动使用 "导出 JSON" 功能，否则该数据不会离开你的设备。你可以随时在扩展的历史标签页中删除所有记录。

权限说明

  • storage / unlimitedStorage — 在本地保存设置和对话历史
  • contextMenus — 为图片分析添加右键菜单选项
  • host_permissions (<all_urls>) — 在任意网页注入解释面板，以及向你配置的 API 端点发送请求

联系方式

如有问题，请在 GitHub 上提交 Issue。
