## Full Description (English)

**Context Explain** brings AI-powered understanding directly to your reading surface — no copy-paste, no new tabs, no lost context.

**Highlight any text** on any webpage and three buttons appear:
• ✦ **Explain** — AI explains the selected text in context, instantly
• ？ **Ask** — Type your own question about the selected passage
• ⇌ **Translate** — Translates to your target language + a brief contextual note

**Right-click any image** to explain what it shows or ask a specific question about it, using a vision-capable model you configure separately.

---

🎯 **WHY IT'S DIFFERENT**

Most lookup tools treat words in isolation. Context Explain sends the surrounding passage alongside your selection, so "Transformer" on an ML paper gets an architecture explanation, while the same word on an engineering page gets something entirely different.

---

✨ **KEY FEATURES**

• AI Explain / Ask / Translate — three modes for three intents
• Image analysis — right-click any image for visual Q&A
• Resizable & pinnable floating panel — drag 5 edges/corners, size saved across sessions
• Full conversation — unlimited follow-ups, full history maintained
• Markdown rendering — tables, code blocks, bold/italic, lists
• Math formulas — KaTeX inline and display LaTeX
• Diagrams — Mermaid flowcharts, sequence diagrams, class diagrams rendered as SVG
• Persistent amber underlines — annotated passages highlighted after page reload
• Scrollbar minimap — see all annotation positions at a glance
• History — full-text search, export JSON, delete individual entries
• UI localization — interface in English / 简体中文 / 日本語 / 한국어
• Retry button — re-run any query instantly

---

🔑 **BRING YOUR OWN API KEY**

Context Explain works with any provider you configure:
• OpenAI (gpt-4o, gpt-4o-mini, …)
• Anthropic Claude (claude-3-5-sonnet, claude-3-haiku, …)
• DeepSeek (deepseek-chat, deepseek-reasoner)
• Any OpenAI-compatible endpoint (OpenRouter, local models via Ollama, etc.)

Your data goes directly from your browser to your chosen API provider — no intermediate servers, no data collection.

---

🔒 **PRIVACY**

• Selected text and context are sent only to the API provider you configure
• No analytics, no telemetry, no accounts, no third-party servers
• All history stored locally via chrome.storage.local

---

🚀 **GETTING STARTED**

1. Click the ✦ toolbar icon
2. Enter your API key and select your provider
3. Optionally configure a Vision API for image analysis
4. Highlight any text on any page — done!

## Full Description (Chinese / 简体中文)

**Context Explain** 让 AI 理解直接出现在你阅读的地方——无需复制粘贴，无需打开新标签页，上下文从不丢失。

**划选任意文字**，出现三个按钮：
• ✦ **解释** — AI 立即结合上下文解释选中内容
• ？ **提问** — 对选中段落提出你自己的具体问题
• ⇌ **翻译** — 翻译到目标语言 + 简短语境说明

**右键单击任意图片**，解释图片内容或对图片提问，使用独立配置的视觉模型。

---

🎯 **有什么不同**

大多数查词工具把每个词单独处理。Context Explain 会把选中内容周围的段落一起发给 AI，所以在机器学习论文里查 "Transformer" 得到的是架构解释，而在电气工程页面查同一个词得到的完全不同。

---

✨ **核心功能**

• AI 解释 / 提问 / 翻译 — 三种模式对应三种意图
• 图片分析 — 右键任意图片进行视觉问答
• 可调整大小的浮动面板 — 拖动 5 个边/角调整，尺寸跨会话保存
• 完整对话 — 无限追问，保留完整历史
• Markdown 渲染 — 表格、代码块、加粗/斜体、列表
• 数学公式 — KaTeX 行内和块级 LaTeX
• 流程图 — Mermaid 图表直接渲染为 SVG
• 持久琥珀色下划线 — 刷新页面后自动恢复标注
• 滚动条小地图 — 一眼看清所有标注位置
• 历史记录 — 全文搜索、导出 JSON、单条删除
• 界面本地化 — 支持 EN / 简体中文 / 日本語 / 한국어
• 重试按钮 — 一键重新运行上次查询

---

🔑 **使用你自己的 API Key**

Context Explain 支持你自行配置的任意服务商：
• OpenAI（gpt-4o、gpt-4o-mini 等）
• Anthropic Claude（claude-3-5-sonnet、claude-3-haiku 等）
• DeepSeek（deepseek-chat、deepseek-reasoner）
• 任意 OpenAI 兼容端点（OpenRouter、Ollama 本地模型等）

你的数据从浏览器直接发送到你选择的 API 服务商，没有中间服务器，没有数据收集。

---

🔒 **隐私**

• 选中的文字和上下文只发送给你配置的 API 服务商
• 无数据收集、无追踪分析、无账户系统、无第三方服务器
• 所有历史记录通过 chrome.storage.local 存储在本地
